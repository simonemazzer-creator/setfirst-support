Informativa sulla privacy

Ultimo aggiornamento: 13 ottobre 2026

SetFirst è sviluppata da Simone Mazzer (Terracina, Italia). Questa informativa spiega quali dati usa l'app.

Dati raccolti

Nessuno. SetFirst non raccoglie, non invia e non vende dati personali. Non usa account, pubblicità, statistiche di utilizzo o strumenti di tracciamento di terze parti.

Dati salvati sul dispositivo

Macchine, utensili, schede di attrezzaggio, lotti di produzione, checklist, laser e preferenze restano solo sul tuo dispositivo. Puoi esportarli e reimportarli con la funzione «Copia di sicurezza»: il file viene salvato dove decidi tu (File, iCloud Drive, e-mail…).

Fotocamera, foto e microfono

La fotocamera e le foto servono solo per allegare immagini alle schede di attrezzaggio e ai controlli qualità; il microfono solo quando tocchi il pulsante per fare una domanda a voce. Le immagini restano sul dispositivo. Il riconoscimento vocale è fornito dal sistema operativo (Apple).

File che apri

I programmi CNC, i disegni DXF/STEP e le tabelle laser che apri vengono elaborati sul dispositivo e non vengono caricati su server.

Invio dei programmi alle macchine

Se colleghi una macchina in rete, SetFirst invia i programmi solo all'indirizzo che hai inserito tu, nella tua rete locale.

Abbonamenti

Gli abbonamenti SetFirst Pro sono venduti e gestiti da Apple tramite il tuo Apple ID: SetFirst non riceve i tuoi dati di pagamento né il tuo indirizzo e-mail. L'app legge da Apple solo lo stato dell'abbonamento (attivo o scaduto) per sbloccare le funzioni.

Minori

L'app è pensata per professionisti e non è rivolta ai bambini.

Contatti

Per domande sulla privacy scrivi a simone.mazzer@yahoo.it.

Privacy Policy

Last updated: October 13, 2026

SetFirst is developed by Simone Mazzer (Terracina, Italy). This policy explains which data the app uses.

Data collected

None. SetFirst does not collect, transmit or sell personal data. It uses no accounts, advertising, usage analytics or third-party tracking.

Data stored on your device

Machines, tools, setup sheets, production batches, checklists, lasers and preferences stay on your device only. You can export and re-import them with the "Backup" feature; the file is saved wherever you choose (Files, iCloud Drive, e-mail…).

Camera, photos and microphone

The camera and photos are used only to attach images to setup sheets and quality checks; the microphone only when you tap the button to ask a question by voice. Images stay on the device. Speech recognition is provided by the operating system (Apple).

Files you open

CNC programs, DXF/STEP drawings and laser tables you open are processed on the device and are not uploaded to any server.

Sending programs to machines

If you connect a machine over the network, SetFirst sends programs only to the address you entered, on your local network.

Subscriptions

SetFirst Pro subscriptions are sold and managed by Apple through your Apple ID: SetFirst never receives your payment details or your e-mail address. The app only reads the subscription status (active or expired) from Apple to unlock features.

Children

The app is designed for professionals and is not directed at children.

Contact

For privacy questions write to simone.mazzer@yahoo.it.

Collegamento in rete con la macchina

SetFirst salva il programma in una cartella di rete che la macchina legge. Telefono, macchina e PC devono essere sulla stessa rete dell'officina.

A · La macchina condivide la sua cartella (Haas NGC)

  1. In macchina: SETTING › Rete › Connessione cablata. Rete cablata abilitata = ATTIVO, poi annota l'Indirizzo IP.
  2. SETTING › Rete › Cond. rete: Cond. rete locale abilit. = ATTIVO e Sicurezza cond. rete locale = ATTIVO.
  3. Nome utente loc: di solito haas. Password loc: scrivi la password, premi ENTER e poi F4 (Applica modif.). Se non la accetta, spegni e riaccendi la macchina e ripeti.
  4. In SetFirst: Officina › Macchine › la macchina › Cartella di rete: indirizzo = IP della macchina, cartella = User Data.
  5. Sull'iPhone: app File › ··· › Connetti al server › smb://IP-della-macchina › Utente registrato › haas e la password della macchina.
  6. In SetFirst: Manda in macchina › Salva nella cartella di rete › scegli User Data. In macchina: LIST PROGRAM › User Data.

B · Cartella sul PC o sul NAS (condivisione remota)

  1. Sul PC Windows: crea la cartella (per esempio C:\CNC), tasto destro › Proprietà › Condivisione › Condivisione avanzata › Autorizzazioni: all'utente metti Modifica (controlla anche la scheda Sicurezza).
  2. Indirizzo del PC: Impostazioni › Rete e Internet › Proprietà › Indirizzo IPv4.
  3. In macchina (Haas NGC): SETTING › Rete › Cond. rete › Condiv. rete remota abilit. = ATTIVO, poi nome server (IP del PC), cartella, nome utente e password del PC › F4.
  4. Sull'iPhone: File › ··· › Connetti al server › smb://IP-del-PC/CNC › Utente registrato › utente e password del PC.
  5. In macchina: LIST PROGRAM › Net Share.

Se qualcosa non va

  • Salva grigio o «Sola lettura»: sei collegato come Ospite o l'utente non può scrivere. In File tieni premuto sul server › Disconnetti e ricollegati come Utente registrato.
  • «Nome utente e password non validi»: nome minuscolo e senza spazi. Su Haas la password vale solo con Sicurezza cond. rete locale = ATTIVO; se non la prende, riavvia la macchina.
  • Due server in File: salva in quello giusto (la macchina o il PC che la macchina legge).
  • La macchina non vede la cartella del PC: controlla cavo, indirizzo e rete. Lascia SMBv1 e NTLMv1 su INATTIVO.
  • Cartella con spazi (User Data): collegati solo all'IP e scegli la cartella dall'elenco.
  • Senza rete: Manda in macchina › Chiavetta USB.

Network connection to the machine

SetFirst saves the program to a network folder the machine reads. Phone, machine and PC must be on the same shop network.

A · The machine shares its own folder (Haas NGC)

  1. At the machine: SETTING › Network › Wired Connection. Wired Network Enabled = ON, then note the IP Address.
  2. SETTING › Network › Net Share: Local Net Share Enabled = ON and Local Net Share Security = ON.
  3. Local User Name: usually haas. Local Password: type it, press ENTER, then F4 (Apply Changes). If it is not accepted, power-cycle the machine and repeat.
  4. In SetFirst: Shop › Machines › the machine › Network folder: address = machine IP, folder = User Data.
  5. On the iPhone: Files › ··· › Connect to Server › smb://machine-IP › Registered User › haas and the machine password.
  6. In SetFirst: Send to machine › Save to network folder › pick User Data. At the machine: LIST PROGRAM › User Data.

B · Folder on the PC or NAS (remote share)

  1. On the Windows PC: create the folder (e.g. C:\CNC), right-click › Properties › Sharing › Advanced Sharing › Permissions: give the user Change (check the Security tab too).
  2. PC address: Settings › Network & Internet › Properties › IPv4 address.
  3. At the machine (Haas NGC): SETTING › Network › Net Share › Remote Net Share Enabled = ON, then server name (PC IP), folder, PC user name and password › F4.
  4. On the iPhone: Files › ··· › Connect to Server › smb://PC-IP/CNC › Registered User › PC user and password.
  5. At the machine: LIST PROGRAM › Net Share.

Troubleshooting

  • Save is grey or "Read only": you are connected as Guest or the user can't write. In Files, long-press the server › Disconnect and reconnect as Registered User.
  • "Invalid user name and password": lowercase name, no spaces. On Haas the password only works with Local Net Share Security = ON; if it is not taken, restart the machine.
  • Two servers in Files: save to the right one (the machine, or the PC the machine reads).
  • The machine can't see the PC folder: check cable, address and network. Leave SMBv1 and NTLMv1 OFF.
  • Folder with spaces (User Data): connect to the IP only and pick the folder from the list.
  • No network: Send to machine › USB stick.
